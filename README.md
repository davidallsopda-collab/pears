# Pears 🍐

Pair-trading phone app. Open https://davidallsopda-collab.github.io/pears/ and add it to your home screen.

- `pears_list.json` - the pairs to track (add a line to add a pair)
- `pears.py` - pulls prices from Yahoo and runs the tests (uses `pairs.py` for the maths)
- `docs/` - the app itself, served by GitHub Pages
- GitHub runs it every 15 minutes while the US market is open

Paper trading only. Not financial advice.
